已知行為（不是錯誤）：
- 角色只做**水平移動**，停在你放的高度；還沒有「地面」或重力的概念。
- **沒有「看向游標」**：Petween 目前不提供全域游標位置給外掛（Phase 1 報告已列為需要新增的 API）。
- 接上 AI agent（Claude Code 等）時，agent 工作中的狀態優先，三人會停止走動直到 agent 閒置。
- Petween 閒置 5 分鐘會進入 `idle.long`；外掛在閒置期間自己決定休息姿勢（站、坐、偶爾小睡）。
- 佔位圖的 `active`、`waiting`、`success`、`error` 只有簡單姿勢。
